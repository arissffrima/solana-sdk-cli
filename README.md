Solana SDK-shaped CLI — path 501, stub lamports.

## Features

- SOL path m/44'/501'/0'
- Deterministic digest (stdlib, no crates)
- Vault + account derive
- cargo test covers keys and wallet

## Prerequisites

- Rust 1.75+
- Git

## Getting Started

```bash
git clone <repo-url>
cd solana-sdk-cli
cargo build --release
./target/release/solana-sdk-cli --help
```

## Tests

```bash
cargo test
```
